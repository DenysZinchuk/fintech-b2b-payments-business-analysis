# FinTech B2B Payments | Business Analysis Case Study

## Project Overview

This project is a Business Analysis case study focused on designing a B2B payment feature for a mobile banking application.

The goal of the product is to enable business users to make fast and secure payments using a contact or identifier while providing transparent fees, transaction limits, payment history and regulatory controls.

## Business Objectives

The solution was designed around several core objectives:

- Fast B2B payment processing
- High transaction success rate
- Transparent fees and limits
- Strong auditability
- AML / Fraud compliance
- Secure payment authorization
